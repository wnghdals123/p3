# Triage Labels

스킬들은 다섯 개의 canonical triage role로 이야기합니다. 이 파일은 그 role을 이 리포의 이슈 트래커에서 실제로 쓰는 label 문자열에 매핑합니다.

| Label in mattpocock/skills | Label in our tracker | 의미                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 메인테이너가 이 이슈를 평가해야 함       |
| `needs-info`               | `needs-info`         | 리포터의 추가 정보를 기다리는 중         |
| `ready-for-agent`          | `ready-for-agent`    | 완전히 명세됨, AFK 에이전트 착수 가능    |
| `ready-for-human`          | `ready-for-human`    | 사람의 구현이 필요함                     |
| `wontfix`                  | `wontfix`            | 조치하지 않음                            |

스킬이 role을 언급하면 (예: "apply the AFK-ready triage label"), 이 표의 해당 label 문자열을 사용합니다.

실제로 사용하는 어휘에 맞추려면 오른쪽 열을 수정하세요.
